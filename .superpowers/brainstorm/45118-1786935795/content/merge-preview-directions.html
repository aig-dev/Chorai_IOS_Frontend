Merge Preview：选择交互方向

三个方案都保留 Chorai 的深紫玻璃语言，并包含完整阅读、编辑正文、Tag 增删、Rate 3 绿色氛围，以及打开 Preview 时隐藏 Merge 浮窗。

1 · 统一卡片画布

Preview / Edit 始终并列，结构最明确；整张卡片滚动，底部操作固定。

2 · 阅读优先

默认像真实 Card 一样审阅；点击右上 Edit 后，在同一画布进入编辑。

3 · 可编辑 Insight 浮层

最接近现有设计图；保留大浮层，内部独立滚动，固定 Header 与操作区。

点击卡片选择。当前建议优先看 2：阅读态更像最终 Card，编辑入口也最轻。
