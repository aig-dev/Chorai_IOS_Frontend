# Chorai · 丰富卡片 V4

这版在独立原生原型里增加八种 Explore 内容，用同一套浏览、阅读与收藏流程观察不同内容的排版。正式 App、此前版本和已导出的旧方案均不受影响。

## 看预览

打开 `gallery/index.html`。网页无需网络、外部字体或第三方依赖；截图资源需与网页一起保留在本目录内。默认展示学院绿金浅色的八种内容，可切换五套配色和浅／深色。

- 内容：图文、长文、摘句、清单、代码、文献、对照、短想法。
- 配色：原版温白墨绿、学院绿金、暮色紫、深海蓝、陶土暖灰。
- 「原版 vs 绿金」：同一种内容同时显示两套方案的浅色与深色。
- 点截图放大；大图支持左右切换内容、更换配色、切换明暗、打开原图。
- 浏览器地址可记录当前选择；直接从本地文件打开时不改写历史记录。

本页展示实际 SwiftUI 截图，只负责看图和比较。拖动、回看、阅读与收藏等交互请在独立原生样本中体验；网页未模拟这些 App 操作。

## 原版与学院绿金

原版温白墨绿沿用 V2 的温白底与森林墨色，深色以中性炭灰为主，没有金色点缀。学院绿金以 William & Mary 的绿金为灵感，保留暖色阅读底，在操作强调中加入少量金色，深色环境也更偏绿。两套都在 V4 里使用相同内容比较，原版 V2 与此前四套配色 V3 仍独立保留。

## 截图约定

原生截图位于 `screenshots/cards/{palette}-{card}-{mode}.png`。完整集共 80 张：

- `palette`：`original`、`green-gold`、`purple`、`blue`、`clay`
- `card`：`photo`、`essay`、`quote`、`checklist`、`code`、`reference`、`comparison`、`short`
- `mode`：`light`、`dark`

截图未就绪时，预览会显示缺图提示；不以网页绘制的假截图代替原生结果。内容、作者与文献均为离线展示样本，不代表真实账号、收藏记录、联网服务或生产接口验证。

## 设计图与原生交互

- `rich-cards-overview.jpg`：学院绿金浅色八种内容总览。
- `rich-cards-dark-overview.jpg`：学院绿金深色八种内容总览。
- `original-vs-green-gold.jpg`：同内容的原版／绿金浅深对照。
- `Open-Prototype.command`：启动独立的 **Chorai Cards V4** 原生样本。
- `ASSET-CREDITS.md`：生成示例图片的来源与完整提示词。

原生样本已在 iPhone 17 Pro / iOS 26.5 上构建；54 个模型断言、5 个针对本轮变化的 UI 测试通过，覆盖八种内容阅读返回、滑动阈值、回看、撤销收藏及外观切换保留状态。最后的小字颜色与图片替代文字调整后重新构建并通过模型检查。具体范围见 `prototype/README.md`。

这轮只扩展本地内容样本和视觉预览。清单是作者内容的展示，文献为虚构示例，运行中的收藏和编辑在重新启动时重置。

浏览器已核对五套配色的浅深模式，共 80 张原生截图全部加载成功，并验证放大、前后切换和原版／绿金四屏比较。独立检查页没有控制台错误。桌面已实看；手机窄屏布局做了规则及交互检查，未将其宣称为真实手机浏览器验证。

版本保留校验：V2 完整原型归档中的 23 个现存文件、V3 归档中的 54 个文件均与原档逐字节一致。V2 归档内部的校验清单不属于原目录文件。正式 App 的既有改动保持原样，本轮设计工作仅在 V4 及版本入口文档内。
