# Chorai iOS · V8 Grid 笔触与详情 Chora

本版按 2026-10-26 的用户选择调整：**Grid 默认不展示小 Chora，保留各级右上角笔触、细边框和等级标记；点进详情后，再显示这张卡对应的小 Chora。** 浏览密度更紧凑，等级仍一眼可辨。

## 这次改变什么

| 场景 | 笔触与等级 | 小 Chora |
| --- | --- | --- |
| Grid | 默认保留右上角彩色笔触、细边框、罗马数字与名称 | 默认隐藏，并移除为角色预留的顶部空白及 IV 专用让位 |
| 从卡片进入详情 | 保留原卡片的等级与对应颜色 | 显示同一级的小型静态形象 |
| 详情返回 Grid | 回到刚才的卡片与浏览位置 | Grid 仍保持隐藏 |
| 原有大尺寸 Flow／Merge 样例 | 补齐笔触，不改等级数据 | 延续原有展示方式，不扩大本次隐藏规则 |

正文点击与菜单中的阅读入口，应携带同一张笔记和同一个等级。阅读和返回不应改变收藏；收藏仍由用户明确点击。笔触与角色不拦截触摸，也不新增升级、抽卡或评级编辑入口。

## 六级共用一套笔触

六档使用同一张已批准笔触的透明形状，按既有等级分别着色：**I 银灰、II 青绿、III 蓝、IV 紫、V 学院金、VI 珊瑚红**。小 Chora 继续复用原画，只有 **V · Exceptional** 使用绿金角色，其余五档保留各自颜色。等级名称和阈值不变，Chora 成长依旧是独立体系。
