# 打磨记录

本轮继续现有 Cosmos 参考方向，修改真实 SwiftUI 入口。没有增加登录方式、账户字段或后端合同。旧原型、旧截图和本轮修改前的源文件分别保留。

## 第一遍：层次与手感

问题：欢迎页三个素材块各自为政；输入页用焦点状态改变顶部留白，叠加键盘避让后产生额外跳动；主按钮没有明确按压反馈。

调整：欢迎页改为主图、错位的学院金纸片和短引文的组合，保留原有三屏内容与固定底部动作。介绍内容使用更短的垂直转场，减少动态效果时改为淡入淡出。统一输入页标题层级、焦点描边、按压反馈、禁用按钮对比和具体加载文案。输入区域依据实际可用高度安排，焦点本身不再额外改变布局。

观察：新的欢迎首屏已通过 Device Hub 读取并保存。Local 与 Production 构建通过，认证相关27项 CoreFlow 检查通过。后续手动操作遇到 Mac 锁屏，不能把只读截图当成手势动效验收。

## 第二遍：返回与恢复

问题：登录→注册→Log In 会重复叠加登录页；从访问码页去登录再返回会覆盖尚未提交的访问码；访问码错误在修改后仍残留；用户名最短长度没有解释。

调整：返回已有登录页并保留草稿；访问码只在首次进入时加载已保存值；真实编辑后清除过期错误；新增错误时滚动显示并播报；用户名提示现有的两字符下限。验证码说明改为有帮助的收件提示，不向用户解释后端实现。

验证：上述四项新的原生交互回归分别执行并通过。验证码的真实校验仍由最终注册请求完成，未添加提前校验成功的文案或假状态。

## 第三遍：大字号与状态变化

代码复查发现：加载文案可能在辅助字号下多占一行，改变按钮高度；兴趣页的居中装饰性 wordmark 可能和 Reset/Skip 重叠。

调整：按钮同时预留空闲／加载文案的排版空间；辅助字号下隐藏装饰性的顶栏 wordmark，保留全部操作；欢迎标题保留完整行高、装饰画按剩余空间缩放；兴趣选项使用稳定左对齐，保持原有9项上限。

最终验证见 QA.md；需要依据实际结果记录，不以构建成功替代运行检查。

## 第四遍：依据实际大字号截图再次修正

12项原生交互检查全部通过后，查看最大辅助字号截图仍发现：隐藏的长加载文案抬高了按钮，确认页协议作为固定底栏占去大量空间，展示型输入字号也过大。通过测试不等于视觉足够清楚。

调整：辅助字号下保留按钮原有可见文字并显示加载指示，完整任务状态仍提供给 VoiceOver；输入使用原生正文语义字号，继续尊重系统最大字号；协议进入可滚动正文，底部只固定主按钮；辅助字号下的兴趣说明减少重复。普通字号仍保留原有表单结构。修改前的大字号截图存于 `captures/accessibility-before/`。

验证：普通注册恢复与最大辅助字号深色完整注册已重新执行，2项均通过，实际截图已更新。最新 Local / Production 构建与27项认证相关 CoreFlow 检查也通过。完整12项流程的通过发生在本轮字号调整前，未将这次2项重跑描述成全部12项重新执行。该阶段的手动检查曾受 Mac 锁屏阻碍；2026-11-04 解锁后已补做，结果见 `QA.md`。

## 第五遍：兴趣选满后的状态反馈

2026-11-04 的截图对照发现：旧版在选满9项后会弱化剩余选项，本轮换用按压样式后，剩余 Photography 仍显示完整墨绿文字与加号，虽然实际已禁用，看起来却仍可继续选择。

调整：仅在兴趣选项局部弱化“未选中且已达上限”的胶囊；已选项继续完整显示并允许取消。保留原有 store、禁用条件、9项限制、44pt最小点击区和共享主按钮样式。此处是状态外观修正，不改变选择行为。

验证：最新 Local／Production 构建通过，既有9项上限及欢迎返回两项回归通过。实际结果包的9项截图确认，Photography 明显弱化，9个已选标签完整显示；保存为独立的 `auth-interests-nine-selected-verified.png`，旧图保留。

## 第六遍：从录屏定位文字重影

正常与减少动态效果的录屏显示，欢迎页转场中旧、新标题会短暂重叠。首次取消标题的独立身份与显式淡入淡出后，逐帧复查仍在15.35秒及26秒看到重影；因此没有把首次修改当成修复成功。

定位：标题和 Next／Get started 文字仍继承整页的 SwiftUI 动画。第二次仅在这两处文字局部取消动画事务，保留插画、背景、分页标记和按钮按压的原有动效。逐帧复查确认第二次修改消除了叠字，但文字先换色、底色仍渐变会造成短暂低对比。最终将动画范围直接限制在插画和分页标记：页面文字、按钮和底色同步切换，内容继续滑动；减少动态效果时只淡入淡出。按钮文案也隔离了同帧按压动画，按压本身的缩放／透明反馈保留。所有中间录屏与说明继续保留，最终验证见 `QA.md`。

最终复核：解锁后完成正常前进、返回和快速连点的原生录屏，文字重影及换色低对比没有复现。另发现中途打开 Reduce Motion 时，旧插画第一次移除仍沿用原有位移过渡；最后将该偏好纳入插画身份，刷新过渡类型。再次录屏确认第一次返回和随后前进均原地淡入淡出。最后一版 Local／Production 构建通过，正常欢迎返回回归在这行装饰性身份调整前已通过；最终身份变化直接以原生录屏检查。两个录屏保留各自真实版本和范围，详情见 `QA.md`。
