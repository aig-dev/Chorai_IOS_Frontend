# 原生入口落地 · 2026-11-03

本轮实现位于原有 Chorai iOS 工程，浏览器交互稿保留在上级目录，未替换或覆盖。

## 实现范围

- 首次进入：短启动、三屏内容介绍；再次冷启动的未登录用户直接进入登录页。退出登录仍回到欢迎页。
- 登录：原生邮箱／密码输入、密码可见性、Google／Apple 入口，实际键盘上方的提交按钮、内联错误与 VoiceOver 播报。
- 注册：访问码预检后，邮箱、验证码、用户名、密码、确认密码逐页填写，原生导航返回保留内容。修改邮箱使旧验证码失效；重发沿用60秒限制，验证码仍由最终注册接口校验。
- 兴趣：原有服务选项、最多9项、重置、跳过和保存。新用户在有效会话恢复后可续接尚未完成的兴趣选择。
- 保留已有访问权限、认证服务、法律文档和幂等键，不增加认证方式或后端字段。

## 验证入口

Local Debug 参数：`--ui-test-auth-entry`。它使用相同原生页面，替换为内存服务，不发送邮件、不调用授权服务、不创建账户，不写入真实登录会话。

虚构测试值：访问码 `UI-TEST-BETA`，邮箱 `reader@example.invalid`，验证码 `123456`，用户名 `TrailReader`，密码 `SamplePass42`。

`CHORAI_AUTH_ENTRY_APPEARANCE=dark` 可指定此离线检查的深色显示。真实应用仍跟随系统外观。

## 验证边界

Xcode构建、模拟器操作与离线测试验证的是界面、状态衔接和已接回的服务调用结构。真实验证码送达、真实Google／Apple授权和后端持久化尚未进行本轮端到端验证；Production只构建、不启动。未另加配乐或声音。触觉／声音与真机性能需要iPhone验收。

最终构建、测试和截图证据见 `QA.md`。
