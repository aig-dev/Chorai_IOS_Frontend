## 怎么看

- 首次进入：Chora 短启动 → 三屏介绍 → Private Beta 访问码 → 邮箱 → 邮箱验证码 → 用户名 → 密码 → 确认密码 → 兴趣选择 → 演示完成。
- 已有账号：Log In → 邮箱与密码，或 Apple / Google 的模拟授权 → 演示完成。
- 手机外的「流程与演示」可重播、直接进入登录或注册、切换浅深色和减少动态效果，并选择正常、拒绝、网络失败、需要访问码四种模拟结果。

请使用虚构信息，例如：

| 输入 | 示例 |
|---|---|
| Product Access Code | `CRAI-DEMO` |
| Email | `hello@example.com` |
| Email code | `123456` |
| Username | `Chora` |
| Password / confirmation | `Chora2026` |

模拟结果由外部演示选项决定；这些值不是有效账号或真实访问凭据。验证码只在最终注册步骤模拟校验，不提前宣称已验证成功。
