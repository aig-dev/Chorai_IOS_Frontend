# Ordinary public NOTE reading

November 28, 2026. Native base: 812b4193f1d027706a31abbd856f971033ae26f2. This slice repairs current inline images in public NOTE reading, not all release gates. The Go companion adds current non-owner authorization around exact media reads; it does not make storage public or allow anonymous content requests.

## Product changes

Detail previously treated the text summary as the complete body and dropped content_json structure. It now uses the shipped BlockNoteCardEditor in read-only mode, the original document adapter and the existing local image scheme. Canonical references override arbitrary props.url through a per-document mapping; the original stored JSON is unchanged. Flow and Library protected previews reuse CardEditorBackgroundImage and the existing scoped download. Exact origin/path/NOTE checks prevent credentials reaching external URLs. Local thumbnails and ordinary unauthenticated remote URLs retain their paths.

Current cardReadSession owns delivery eligibility. Temporary verification/degraded connectivity keeps delivered structured text while disabling protected image downloads; canonical locators have no fallback to unauthenticated sources. Canceled preparation cannot retire its successor, and session/document replacement rejects late bytes. Read-only bridge Retry recreates the same readonly model and mapping; compatibility blocks still prevent retry. CSS hides only readonly node-selection decoration, with editable selection as the positive control.
