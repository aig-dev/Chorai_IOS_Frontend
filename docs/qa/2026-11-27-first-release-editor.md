# First-release embedded editor boundary

The shared Web source now restricts ordinary NOTE initialization and transactions to the retained first-release document representations. Canvas, Mindmap, tables, toggle headings/lists, inline code, custom numbering and other unsupported blocks cannot enter a publishable draft. Existing unsupported documents retain their original stored JSON and use the existing read-only compatibility state. Rejected input shows a nonfatal message; it does not terminate the native editor session.

The shared schema retains the existing optional image mediaRef. Native runtime projection and merge-back remain owned by BlockNoteEditorState; no Swift bridge protocol or local-store migration is added. Protocol 3, schema 1, Swift 6 and iOS 16 remain unchanged. The resource bundle is generated by the Web repository's `npm run build:ios-editor` and checked with `npm run check:ios-editor`.

The real generated browser bundle exposed a first attempt that inspected BlockNote changes before pasted nodes had IDs. That attempt is superseded. The final guard inspects proposed ProseMirror nodes before commit; actual DOM clipboard regression tests and browser interaction verify whole-transaction refusal and normal multi-block paste. The pinned fixture covers retained text, headings, nesting, list/check/quote/code blocks, styles, links and image identity through both editor schemas and Go preparation/response serialization.

Web's final suite has 1,122 passing tests, plus clean TypeScript, build and resource consistency checks. Browser checks use a controlled component and fixture image response without account credentials. They are not ordinary API qualification or device performance measurements.

The final required native gate passed persisted Swift 6 and complete checking, 26 runner tests, 1,110 CoreFlow tests, 76 BlockNoteEditor tests, 143 App-hosted tests and all ten required fixture-backed simulator flows. ArcNote Debug and ArcNoteProduction Debug-Production / Release builds passed. CoreFlow executed 1,116 cases with six opt-in live API skips and zero failures; the six skips are excluded from the passing count. A subsequent separate ordinary-account run against the current isolated prod API passed all six with zero skips; see the [runtime qualification and limits](2026-11-27-ordinary-release-runtime.md). The earlier interrupted gate is excluded. Previous live API results are not reclassified as this source's acceptance.

The current isolated prod runtime's same-note ordinary-account cross-client loop is now qualified in the [full-document record](2026-11-27-cross-client-note.md). R3 remains open for final retained Merge integration and the other required failure combinations. Workspace, new strict NOTE Fork, old-data migration and CI/CD remain outside this release cut.
